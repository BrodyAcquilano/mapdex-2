# Mapdex

Mapdex is a full-stack spatial data platform for building, managing, and exploring custom map-based projects.

It is designed to work with many kinds of location-based data, not just public resources. A project can be configured to map places, infrastructure, services, routes, environmental features, community assets, or other geographic datasets.

## What it does

Mapdex combines interactive mapping, filtering, and data management in one interface. Depending on the version or user role, it can be used to:

- view and explore map data
- filter records by project-defined fields
- open location details in a structured info panel
- add, edit, and manage spatial records
- support separate viewer and editor workflows

## Main idea

The goal of Mapdex is to provide a flexible system for custom mapping projects without hardcoding the app around one single use case. Instead of being limited to one dataset type, Mapdex is built to support different project structures and different kinds of spatial information.
